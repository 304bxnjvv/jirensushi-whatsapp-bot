# MVP Viña del Mar Implementation Plan

> **For agentic workers:** Use Superpowers TDD, independent bounded tasks and verification before completion. User has authorized continuous execution; stop only for sensitive credentials or truly unavailable external access.

**Goal:** Implement every active HU/TEC as runnable software, with a local simulator and authenticated staff panel.
**Architecture:** One Cloudflare Worker, D1/SQLite, versioned JSON menu, a deterministic conversation state machine with optional OpenAI interpretation, and same-origin static panel. Durable inbox/outbox and database transactions protect orders from duplicate messages and concurrent actions.
**Tech Stack:** TypeScript, native Fetch/WebCrypto, SQLite, Cloudflare Workers/D1, vanilla browser modules, Node test runner.
